## 1. 装好之后第一眼

窗口分三块：

```
┌──────────────────────────────────────────────┐
│ ☰ LiteShell      🎨 日志 ⌘ 🔑 ⌨ ⚙            │  ← 标题栏
├───────────┬──────────────────────────────────┤
│ 连接       │ 标签页                            │
│ ▸ 我的机器 │ ┌──────────────────────────────┐ │
│   生产     │ │ 工具栏                        │ │
│   测试     │ ├──────────────────────────────┤ │
│            │ │ 终端（左边）/ 文件·监控·AI（右）│ │
│            │ └──────────────────────────────┘ │
├───────────┴──────────────────────────────────┤
│ 就绪                                  host   │  ← 状态栏
└──────────────────────────────────────────────┘
```

标题栏右边那排按钮，从左到右：**配色**、**日志**、**命令面板**、**私钥库**、
**快捷键一览**、**设置**。侧栏顶上有 **导入**（从 FinalShell 搬连接）和 **＋**（新建连接）。

左侧可以通过标题栏的 ☰ 收起来（`Ctrl+B`），窄屏上很有用。

## 2. 建第一条连接

点左边 **＋**，填：

| 字段 | 说明 |
| --- | --- |
| 名称 | 随便起，之后在命令行、AI 对话里都用它指代这台机器 |
| 主机 / 端口 | IP 或域名，端口默认 22 |
| 用户 | 登录名 |
| 认证方式 | 密码 / 私钥 / SSH Agent |

**如果你从 FinalShell 来**：不用手填。侧栏「导入」→ 选 FinalShell 的安装目录
（里面是 `config.json` 和一堆 `*_connect_config.json`），连接树、主机、端口、私钥会整个搬过来，
里面存的密码也会自动解密并存进系统钥匙串。

第一次连一台机器会记下它的主机指纹（TOFU）。之后打开的每次连接都按这个指纹校验，
**指纹变了直接拒绝**——那是有人可能在中间冒充服务器的信号，不要点"继续"。

连上之后，标签上的绿点表示会话活着，红点是断开了。

## 3. 连接界面：一块地方做四件事

一个标签页就是一台机器。左边永远是终端，右边可以拉出三个面板（工具栏上的按钮开合）：

| 面板 | 按钮 / 快捷键 | 干什么 |
| --- | --- | --- |
| **文件** | `Ctrl+Shift+B` | SFTP：浏览、上传、下载、改名、改权限、在线编辑 |
| **监控** | `Ctrl+Shift+M` | CPU / 内存 / 磁盘 / 网络 / GPU / 进程，连上时自动打开 |
| **AI** | 工具栏「AI」 | 用中文让它在这台机器上做事 |

三个面板之间、以及终端和面板之间都有分隔线，可以拖。AI 面板标题栏的 **⤢** 让它占满整行，
**⧉** 把它弹成独立窗口（另一个显示器上用）。

## 4. 日常操作：补全、历史、快捷命令

- **输入时就给候选**：在光标下面浮出一行候选（像输入法的候选条），出现在输出的上方，
  **不会把终端挤动**——命令行一直在原地。`↓` 进入候选开始选，`↑` 退回你原来输入的内容，
  `Tab` 或点一下补全，`Enter` 执行。词典里有 205 条常用运维命令——
  这是在你**还没想好完整参数**的时候帮忙的，不是替代 shell 的 Tab。
- **命令历史**：每条连接一份，存在本地，重启还在。`Ctrl+Shift+H` 打开搜索框；
  输入时也能直接把历史补出来。
- **快捷命令条**：终端下面那行小胶囊，可以存常用的几条命令，点一下就打到命令行。
  旁边的「广播」打开后，**你敲的命令会同时发到所有已连接的标签页**——批量重启一次服务很方便，
  但它是真的会同时在生产的每个窗口里执行，用之前先确认开着的都是哪几台。
- **命令面板**：标题栏 **⌘**，205 条带完整参数的命令，可搜，鼠标划过看说明，点一下填进命令行。
  比背参数快。

## 5. 传文件与改文件

点工具栏 **文件** 打开 SFTP 面板：

- **传**：把文件从访达 / 资源管理器直接**拖进面板**。或者点上传按钮选文件。底部有每条传输的进度。
- **下**：右键文件 →「下载」，或选「打包下载」把整个目录压成一个文件传下来。
- **改**：**双击文本文件**直接打开内置编辑器，`Ctrl+S` 存回服务器。二进制、压缩包、
  超大文件会被挡下——不是为了刁难你，是打开一个 200 MB 的日志只会让界面卡死。
- **管**：右键能新建、重命名、改权限、删除、复制路径。

上传下载都在底部的传输清单里，带进度、可以清空。

## 6. 看服务器的状况

监控面板在**连上的那一刻自动打开**（只对当前标签生效），之后每 2 秒刷新一次，关掉就停。

最上面是一行**结论**：正常就一行绿字「CPU / 内存 / 磁盘 都正常」；有事才变成橙色或红色的胶囊，
比如「内存 92%」「/data 已用 92%」，严重的排在前面。下面是四张卡片（CPU、内存、Swap、网络），
再往下是 GPU、每个磁盘挂载点、**最忙的 10 个进程**（含命令行和可执行文件路径）、网卡。
每块都能点标题折起来。

不用跑 `top`、`free`、`df` 了——它读的是同样的地方，但整理成了能一眼看完的形式，
而且**不碰你的 shell**：它走独立通道，你 `history` 里不会多出一堆监控命令。

## 7. 让它记住你：私钥库与免密登录

两件不一样的事，常常被混淆：

**私钥库**（标题栏 🔑）：把私钥**导入一次**，之后建连接时从下拉里选就行，不用每次翻文件。
加密私钥的口令也只输一次，之后复用它建立的每个连接都不再问。
库里每个条目可以改名、写备注、导出、删除。

**配置本机免密登录**（连接右键）：目标是让**本机命令行**直接 `ssh 主机` 就能连上。
它会生成一把专用密钥、装到服务器的 `authorized_keys`、**再用这把新密钥登录一次确认真的通**，
最后在本机 `~/.ssh/config` 里写一段带标记的 Host 块。同一个 IP 有多条连接时会自动
分成 `10.0.0.1`、`10.0.0.1-a`、`10.0.0.1-b`。

## 8. 用中文操作：AI 助手

先去 **设置 → AI 助手** 填三样东西：**接口地址**、**模型**、**上下文窗口（K）**。

- 接口地址：用 Anthropic 就留空或用官方地址；自建网关 / DeepSeek / Ollama 选「OpenAI 兼容」
  填到 `/v1` 为止。填完点**「拉取模型」**从接口读模型列表，不用背模型名。
- API Key：**可以不填**（本地 Ollama、内网网关通常不要）。填了就加密存进系统钥匙串。
- 上下文窗口：填模型实际能装多少（K 为单位）。设小了会频繁压缩，设大了可能超出接口上限。

然后点工具栏 **AI**，直接说人话：

> 「磁盘还剩多少」
> 「看看 /var/log/nginx 下面最近的错误」
> 「把 nginx 的 worker_processes 改成 auto，然后 reload」

它会把命令**打在左边那个终端里执行**——你看得见它下命令，看得见输出，`Ctrl-C` 随时能掐。

**什么时候会停下来问你**：只有会删数据、覆盖文件、不可逆的改动（`rm`、`mv` 覆盖、
重定向覆盖、`kill`、删库表、传文件）。只读的（`ls`、`cat`、`tail`、`grep`、`ps`、`df`、
`systemctl status`…）直接跑；可逆的改动（重启服务、改权限、装包）也直接跑。
弹出来的确认卡上**命令是可以改的**——改完会重新过一遍风险判定，不然这张卡就成了夹带别的东西的通道。

**对话会存下来**，按连接记。面板右上角「历史」（或工具栏 AI 按钮右键）里点开一条，
「继续这个对话」就接着往下问，它记得之前跑过什么。

**上下文太长会自动压缩**：到了窗口的 90%，早先那段会被同一个模型压成交接摘要
（命令原文、路径、数值、报错、被拒绝的尝试都照抄），最近的部分原样留着。
对话里会出现一行「早先的对话已压缩成摘要」，点开就能看你模型现在手里握住的是什么。
这不是失忆，是把"三小时前那次 `df` 的输出"换成了"`/data` 当时 92%"。

## 9. 让别的 AI 客户端也能操作

LiteShell 自带一个**技能包**：一份 `SKILL.md`（告诉 AI 什么时候用、怎么用）和一个
命令行小工具（`liteshell-cli.mjs`）。这个 CLI **没有一行 SSH 代码**——它通过本机 socket
让**正在运行的 LiteShell** 去干活，所以凭据、已知主机、连接复用全走界面里那一套，
AI 永远拿不到你的密码。

导出：**设置 →「导出 CLI + 技能包」** → 选一个目录，会生成 `<目录>/liteshell/`，
里面是 `SKILL.md`、`bin/liteshell-cli.mjs` 和一份 `README.md`（各客户端的安装办法）。

- **Claude Code**：把 `liteshell/` 整个复制到 `~/.claude/skills/`（Windows 是
  `%USERPROFILE%\.claude\skills\`），重启 Claude Code。
- **支持技能目录的客户端**（Cline、Roo Code、Cherry Studio 等）：放进它约定的技能目录。
- **只有 rules / 自定义指令的客户端**（Cursor、Windsurf、Codex CLI 等）：把 `SKILL.md`
  的正文粘进 rules，把里面的 CLI 路径换成绝对路径。
- **什么都不支持**：导出的 `README.md` 里有一段可以直接粘进对话的说明。

前提：本机要有 Node.js，而且 **LiteShell 必须开着**（收进托盘不算关）。CLI 只连本机，
不联网，跑过的每条命令记在 `<用户数据目录>/cli-audit.log`。

细节见[给 agent 用（CLI）](agent-cli.md)。

## 10. 换个样子

- **主题**：标题栏 **🎨**，7 套配色（含亮色），**鼠标划过即预览**，点一下才真的换。
- **终端背景图片**：设置 →「终端背景图片」→「选择图片…」。图片画在文字后面，
  配色里的背景色变成半透明遮罩，所以黑底白字压在一张风景照上还看得清。
  只记路径不存副本——图片留在你原来的文件夹里，删了背景就没了。
- **字体、字号、光标、回滚行数、选中即复制**：都在设置里。
- 所有外观设置都只是偏好，不影响连接和安全。

## 11. 换机器、备份、迁移

侧栏每个菜单里都有导出：

| 导出什么 | 在哪 |
| --- | --- |
| 全部连接 | 侧栏空白处右键 →「导出全部连接」 |
| 单个文件夹 | 文件夹右键 →「导出这个文件夹」 |
| 单条连接 | 连接右键 →「导出这条连接」 |

导出时设一个**口令**，密码、私钥口令、AI 的 API Key 就会用这个口令加密跟着走——
对面导入后一条都不用重输。不设口令也能导，但里面只有连接信息，密码得重新填。
**私钥文件本身始终是明文**，导出文件要当私钥一样保管。

导入在同一个菜单里。文件放在哪儿见[开发与构建](development.md#配置文件位置)。

## 12. 出问题了看哪里

| 现象 | 先看 |
| --- | --- |
| 连不上 | 标题栏 **日志**：完整握手过程、认证方式、失败原因都在里面 |
| 主机指纹变了被拒 | 这是安全拦截，不是 bug。确认这台机器是不是重装 / 换密钥了，再决定要不要清掉记录 |
| AI 发出去没反应 | 面板会说"正在请求…"直到第一个字。两分钟超时、接口报错、空回复都会写进对话 |
| AI 说地址不对 | 自建网关多半少了 `/v1`。填到 `/v1` 为止 |
| 传文件失败 | 文件面板底部传输清单里有每条失败原因 |
| 别的 AI 客户端连不上 LiteShell | 多半是 CLI 报了 `app_not_running`——把 LiteShell 打开（托盘里也算开着，退出才算关） |
| 想确认某个动作能不能撤回 | 见[安全模型与取舍](security.md) |

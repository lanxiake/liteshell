# 安全模型与已知取舍

[返回 README](../README.md)

## 凭据怎么存

- **密码、API Key、私钥口令**经系统钥匙串（Windows DPAPI / macOS Keychain / Linux libsecret）加密后
  写进 `liteshell.json`。系统没有可用钥匙串时，退回同目录的 `vault.key`（0600）做 AES-256-GCM。
- **IPC 边界上只传密文**：渲染进程永远拿不到明文密码，只看到 `hasSecret` 这样的布尔标记。
- **主机密钥 TOFU**：首次连接记录指纹，之后变化直接拒绝并提示，防中间人。
- **导入/导出备份**：密码和私钥口令只有在你给导出设了口令时才跟着走，那时用 scrypt(32 MB) +
  AES-256-GCM 加密；不设口令就留在本机钥匙串里，别的机器解不开。口令错误或文件被改动会整体拒绝导入。

## 已知取舍

- **导出包里私钥是明文**（base64 的 PEM，和 FinalShell 自己的 `config.json` 一样）。
  文件按 0600 写，但既然是明文，传出去就得自己负责。
- **私钥库里的密钥是明文文件**，放在 `<用户数据目录>/keys/`（0600），和 FinalShell 的做法一致。
  密钥本身的口令存在钥匙串里、连接时交给 ssh2 解密，但 LiteShell 不会把密钥文件重新加密。
- **「配置本机免密登录」会改动你的 `~/.ssh`**：生成一把**没有口令**的私钥
  `~/.ssh/liteshell_ed25519`，把公钥追加到服务器的 `authorized_keys`，并在 `~/.ssh/config`
  顶部写一段带标记的 Host 块。无口令是让 `ssh IP` 不用再输入；拿到这个文件就等于拿到该服务器账号，
  请按密码对待。只加公钥、不改服务器上已有的条目；同一主机的 LiteShell 块会被替换。
- 依赖 `nvidia-smi` 看显存；没有 NVIDIA 卡就只显示 CPU / 内存 / 磁盘
- 终端编码固定 UTF-8（FinalShell 的连接配置里也全是 UTF-8）
- 暂无 ProxyJump / 端口转发 / 跳板机链路
- 暂无 X11 转发、ZMODEM 传输
- 应用图标是 `scripts/make-icon.mjs` 用距离场画出来的（`npm run icon`，无图形库依赖），
  要换成正式设计稿直接覆盖 `build/icon.png`（512×512 起，`.ico` / `.icns` 由 electron-builder 现生成）
- **AI 助手会把服务器上的东西发给你配的那个模型**：只读工具返回的文件内容、命令输出都在里面。
  介意就别让它 `cat` 敏感文件——闸门管的是「会不会改坏」，不是「能不能外传」。
- AI 的写闸门是**绊线不是边界**：`src/main/gate.ts` 是纯正则分类器，判不准的一律按危险算，
  但它拦不住 `awk 'BEGIN{system("…")}'` 这种把命令藏在参数里的写法。真正的边界是你点的那一下。
- 只读工具自动跑，只读的 `exec` 命令也自动跑（见 [功能详解](features.md#ai-助手)），其余每条都要点一下。
  **没有「本次全自动」这一档**，也还没有按主机记的信任范围——等真实使用里的打扰频率有数了再说

# 功能详解

[返回 README](../README.md)

## 功能总览

- **连接管理**：文件夹树，密码 / 私钥 / SSH Agent 三种认证；右键可复制 IP、重命名、导出单条连接
  （带密码或只带连接，取决于导出时设不设口令），整份备份也是一个 JSON 文件
- **本机免密登录**：右键连接 →「配置本机免密登录」，见[下面](#本机免密登录)
- **远程桌面**：右键连接或终端标签 →「远程桌面 (RDP)…」，经 SSH 隧道打开远程图形桌面，见[下面](#远程桌面rdp-over-ssh)
- **私钥库**：私钥先导入成列表（可改名、加备注、导出），新建/编辑连接时直接挑一把，
  不用每次翻文件；没被任何连接引用的私钥也会跟着备份一起走
- **多标签终端**：xterm.js，可调字体字号、配色、光标、回滚行数；标签上的绿点表示已连接、
  红点表示已断开，右键可复制 / 重连 / 断开 / 关闭其他 / **在新窗口中打开**（多屏各看各的）
- **资源监控**：连上标签页自动打开，CPU / 内存 / Swap / 网络带实时曲线，加 GPU、磁盘、进程表和服务器信息，
  每块可折叠
- **SFTP 面板**：面包屑可点、路径可直接输入、右键行内重命名/复制路径/打开/下载/删除；
  目录与文件按类型上色（`ls --color` 那套习惯）；**文件可直接拖进面板上传**，带进度和清单
- **内置编辑器**：双击文本文件直接改，`Ctrl+S` 存回服务器；压缩包、二进制、超大文件会被挡下
- **命令补全**：输入时在**输入行下方**弹出候选（像输入法），历史 + 内置常用命令词典，
  `↓` 从顶部进入候选、`↑` 退回，Tab 补全、Enter 执行；历史按连接记到 `liteshell.json`
- **界面文字可选中**：状态栏、监控卡片、日志、文件行都能拖选复制，右键还有「复制选中内容」
- **命令面板**：内置 205 条常用且专业的运维命令（系统信息、权限、内核调优、磁盘、进程、网络、
  SSH、文本处理、日志、Docker、K8s、Helm、Nginx、MySQL/Redis、压测、GPU、安全审计…），
  可搜索，鼠标划过看完整命令与作用，点击填入命令行
- **AI 助手**：直接用中文让它在这台服务器上做事（看图、看日志、改配置），
  只读的自己跑，**改动服务器的每一条都要你先点确认**；Anthropic 官方接口，或任何 OpenAI 兼容接口
- **快捷命令 + 广播**：一键把同一条命令发到所有已连接会话
- **主题**：7 套配色（含亮色），标题栏「🎨」，鼠标划过即预览
- **主机密钥 TOFU**：首次连接记录指纹，之后变化直接拒绝（防中间人）
- **明文不落盘**：密码经系统钥匙串加密后存储；IPC 边界上永远只传密文
- **从 FinalShell 导入**：侧栏「导入」按钮选一个 FinalShell 目录，连接树、主机、端口、用户名、认证方式、私钥一并搬过来；
  单个 `*_connect_config.json` 也能从侧栏或目录右键导入，存着的密码会自动解密并存入钥匙串
- **导出连接**：同一菜单里「导出全部连接」，连私钥、模型配置一起打包成一个 JSON，换机器直接导入；
  导出时给一个口令，密码和 API Key 就用它加密跟着走，对面导入后一条都不用重输
- **日志面板**：标题栏「日志」，含每条连接的握手细节、认证过程、失败原因
- **收进托盘**：点窗口的 × 不退出，只是收进系统托盘（左键点图标回来，右键 → 退出才真退出），
  会话和 agent 的连接都留着

## 资源监控

一条 `exec` 命令跑完，不用 sudo，也不碰你的 shell（走独立通道，shell 里的 `history` 干干净净）。
脚本里 `sleep 1` 采两次 `/proc/stat` 和 `/proc/net/dev`，所以 CPU% 和网速是**真实速率**而不是
开机以来的平均值。GPU 走 `nvidia-smi`，没装就显示「未检测到 NVIDIA 显卡」而不是报错。

打开标签页连上服务器时，监控面板**自动打开**（只对当前标签生效，后台附加的会话不会偷偷开始采样）；
之后点工具栏「监控」或 `Ctrl+Shift+M` 开合。开着每 2 秒刷一次，关掉就停采样，不在后台空转。

面板按「先看结论，再看细节」排：顶上是预警条——正常情况下就一行绿字，「CPU / 内存 / 磁盘 都正常」；
有事才变成橙/红胶囊，例如「内存 92%」「/data 已用 92%」，严重的排前面。阈值集中在
`src/renderer/src/alerts.ts` 一张表里（CPU 80/95、内存 85/95、Swap 60/85、磁盘 80/90、
显存 85/95、GPU 温度 75/88、每核负载 1.5/2.5），数字和颜色都从这张表来，改一处就够。

下面 CPU / 内存 / Swap / 网络 四张卡排成两列，一屏看完不用下拉；CPU 和内存各有曲线和进度条
（曲线看趋势，进度条看当下），网络只有曲线。再往下依次是 GPU（型号、利用率、温度、显存）、每个挂载点
（只列真实文件系统，`tmpfs` 这类不占盘的会被滤掉，设备名在悬停提示里）、**进程表**和网卡列表。
进程表按 CPU 倒序取最忙的 10 个，列 PID、用户、CPU、内存、磁盘读 / 写、名称、完整命令行、可执行路径；
`/proc/<pid>/exe` 读不了别人的进程时，位置那一栏退回命令行而不是留空——同样不需要 sudo。
每块（GPU / 磁盘 / 进程 / 网络）点标题就能折起来，默认全开，折叠状态在一次会话里记着，
采样刷新只重写内容、不会把折起来的那块弹开。

`npm run test:alerts` 用一份合成的健康机器跑阈值规则：哪里该静默、哪里该报、报出来谁排前面。
`npm run test:monitor` 拿一份手工抓的 `@@SECTION` 原始输出跑解析器：速率按两次采样之差算、回环不进总量、
`tmpfs` 被滤掉、读不到 `exe` 的进程退回命令行，还有各种缺工具的降级情形（没有 GPU、没有 `/proc/net/dev`、
老内核没有 `MemAvailable`）。

## 文件面板

- **面包屑可点**：路径的每一段都能点回去；`✎` 或双击面包屑直接手输/粘贴路径跳转
- **行内右键菜单**：编辑、上传到此处、下载、打包下载（服务器上 `tar` 成一个文件再拉回来）、
  新建文件夹 / 新建文件、文件权限（chmod）、重命名、复制路径、删除、递归删除、刷新
- **按类型上色**：目录、可执行脚本、压缩包、图片音视频、代码配置各一色，跟 `ls --color` 的直觉一致；
  颜色取自主题的终端调色板，换主题自动跟着变
- **双击**：目录进入，文件直接进内置编辑器（不适合编辑的会问你一句，再交给本机程序）
- **空白处右键**：上传到此处 / 新建文件夹 / 新建文件 / 复制当前路径 / 刷新
- 首行工具栏：⬅ 上一级、⟳ 刷新、🗀 新建、⬆ 上传、⋯ 更多（复制当前路径等）
- 拖文件进来即可上传，面板底部是**传输清单**：上传和下载各占一行，带方向箭头和单条进度；
  「清空」只清已结束的，正在传的留着

## 文件编辑器

双击一个文本文件就地打开，改完 `Ctrl+S` 直接写回服务器 —— 不用下载、改了再传。

哪些文件能进编辑器，是一道三层闸门（都在 `src/main/textfile.ts`，有独立单测）：

1. **扩展名黑名单**：压缩包（zip/tar.gz/7z…）、二进制（exe/so/class…）、文档、图片音视频、字体、数据库
2. **内容嗅探**：有 `0` 字节、或控制字符超过 5%，按二进制处理
3. **严格 UTF-8 解码**：解不出来（GBK 等）也不给你编辑，免得存回去把文件搞坏

另外超过 **2 MB** 的文件直接劝退 —— 大文件在文本框里编辑本来就不是好主意。挡下来的文件不会
静默失败：说明原因，再问你一句要不要「改用本机程序打开」（下载到临时目录交给系统默认程序）。

保存走的是 `临时文件 → chmod 沿用原权限 → rename`，中途断线也不会把原文件截断成半截。
写之前会比对 mtime：如果这期间别人也改了同一个文件，先弹确认再决定要不要覆盖。

## 私钥库

标题栏 **🔑** 打开。导入一个 PEM（`.pem` / `.key` / `.ppk` / 无扩展名都行），它会被**复制**一份到
`<用户数据目录>/keys/`（0600），原来的文件不动 —— 所以之后无论你在哪儿删它，LiteShell 里的这把还能用。

| 能做 | 说明 |
| --- | --- |
| 改名 / 备注 | 菜单里显示的是名称而不是路径；备注写「生产跳板机」这种 |
| 设置 / 修改口令 | 加密私钥的口令存进本机钥匙串，**所有复用这把私钥的连接都不用再输**；留空即清除 |
| 导出到文件 | 另存一份出去，库里的照旧留着 |
| 删除 | 只从列表里移除；**仍有连接在用它时文件保留**，不会把连接连坐搞坏 |

导入时如果私钥有口令，会当场问一次（没有就直接留空），口令跟着这把密钥走。
连接建立时按「本次输入 → 连接自己的密码 → 私钥库条目的口令」依次取用。

新建 / 编辑连接时，「私钥文件」是一个下拉：库里所有密钥都能直接挑，下面一行显示实际路径。
按钮「导入」= 挑个新文件并选中它，「浏览」= 用一个不进库的文件（老连接、临时密钥）。
**不在库里的路径会作为一行「（不在私钥库）」保留**，原样保存不会把它清掉。

导出备份时，库里**没被任何连接引用**的私钥也一起打包（这正是「先攒起来备用」的意思）；
导入备份则会把密钥列表一并重建。从 FinalShell 导入的连接，其私钥也会自动进库。

## 本机免密登录

连接列表右键 →「配置本机免密登录…」。用这条连接已有的密码 / 私钥 / agent 登录一次，然后：

1. 在本机 `~/.ssh/liteshell_ed25519` 生成一把无口令的 ed25519 密钥（已有就复用），
   文件权限收紧到仅当前用户可读
2. 把公钥追加进服务器的 `~/.ssh/authorized_keys` —— 已经存在就不重复写，权限一并收成 700/600
3. **用这把新密钥再登录一次**，确认服务器真的接受公钥认证（`PubkeyAuthentication no` 会在这里直接报错）
4. 在 `~/.ssh/config` 顶部写入一段带 LiteShell 标记的 Host 块：用户名、非 22 时的端口、
   `IdentityFile`、`IdentitiesOnly yes`

完成后本机终端里直接：

```bash
ssh 10.157.150.22
```

同一主机再配置一次会替换旧块而不是堆叠，你自己其他的 Host 配置原样保留。
**别名在全部连接里唯一，不分文件夹**：别的目录下也有 `10.157.150.22` 时，后配的那条拿到
`10.157.150.22-a`，再往下 `-b`…；已经分好的名字没人抢就一直留着。
私钥没有口令（否则每次 `ssh` 还要输一遍），请把它当密码保管。

## 远程桌面（RDP over SSH）

连接列表或终端标签右键 →「远程桌面 (RDP)…」。LiteShell 用这条连接的 SSH 凭据经 `direct-tcpip`
通道接到远端的 RDP 服务（默认 3389）。对话框里有两种打开方式：

- **内嵌打开**：远程桌面画在 LiteShell 的独立窗口里（IronRDP WASM）。鼠标、键盘、滚轮、文字剪贴板
  都直接可用，窗口右上角可以全屏。RDP 密码在对话框里填一次，只留在主进程内存和这个窗口的 CredSSP
  握手；窗口关闭即丢弃，不写盘、不进日志。需要 NLA 的 GNOME 和不需要 NLA 的 xrdp 都支持。
- **系统客户端**：LiteShell 在本机 `127.0.0.1` 上开一个临时端口，拉起系统 RDP 客户端。RDP 密码
  由客户端自己询问，LiteShell 不保存。

两种方式下桌面服务都不需要对网络开放，防火墙上只要留着 sshd 就够。

- **Ubuntu 22.04+（GNOME）**：设置 → 系统 → 远程桌面，打开「远程桌面」和「远程控制」。
  新版 GNOME 走 RDP，Wayland 下旧的 VNC 后端已经不用了。这里的登录用户名通常是桌面登录用户，
  密码是「远程桌面」里设置的密码，不一定等于 SSH 密码。
- **其他发行版或想要独立会话**：安装 xrdp，让它监听 3389 即可。
- **Windows（Pro / Enterprise / Education）**：设置 → 系统 → 远程桌面，打开「远程桌面」。账号必须有
  密码，默认走 NLA/CredSSP。**家庭版没有 RDP 服务端**。隧道是从这条连接自己的 SSH 会话里转发的，
  所以这台 Windows 必须自己跑着 sshd：启用可选功能「OpenSSH 服务器」并启动服务。
  登录用户名按 Windows 写法填（`用户名`、`主机名\用户名` 或 `域\用户名`）。Pro 版同一时间只允许一个
  远程会话，连上去本地控制台会被锁掉。
- 对话框里可以改 RDP 端口和登录用户名；勾选「记住端口和用户名」会写回连接配置，用户名默认取 SSH 用户。
- 内嵌模式的密码框只用于本次打开；系统客户端模式会忽略它。两种模式的 RDP 密码都不保存，
  也不会拿 SSH 密码去猜。
- 隧道只绑 `127.0.0.1` 上的随机端口；客户端退出、内嵌窗口关闭或 SSH 断开时，监听一起清理
  （系统客户端模式下还有临时 `.rdp` 文件）。

内嵌模式多一层本地代理：主进程起一个只监听回环地址的 RDCleanPath WebSocket 服务，URL 路径和请求体
里各带同一枚随机 token，不知道 token 的连接直接拒绝。浏览器端做不了 TLS，所以代理替它终止 TLS 并
把服务器证书指纹写进日志；主机身份仍然由 SSH 主机密钥保证。页面 CSP 只为内联的 WASM 放开了
`wasm-unsafe-eval`，没有放开 `unsafe-eval`。

用系统客户端首次连接会看到证书名称不匹配的提示：客户端连的是 `127.0.0.1`，而证书上的名字是服务器
主机名。这台机器已经由 SSH 主机密钥认证过，确认指纹无误后接受即可——这条隧道的信任根在 SSH，不在
RDP 证书。内嵌窗口不弹这个提示，因为代理已经替它接受了证书并记录了指纹。

各平台的系统客户端：Windows 用自带 `mstsc`；macOS 需要 App Store 里的「Windows App」或
「Microsoft Remote Desktop」；Linux 优先 `xfreerdp3` / `xfreerdp`，其次 `remmina`。
内嵌窗口不依赖这些客户端，三个平台一样。

> 内嵌 RDP 的失败路径（没有 RDP 服务、转发被拒）有冒烟测试覆盖；成功画面需要一台真正开着
> GNOME 远程桌面或 xrdp 的机器，仓库的测试环境里没有这样的目标，因此尚未端到端验证。

## 命令面板

标题栏 **⌘** 打开。内置 **205 条**带完整参数的运维命令，按 25 个分组排（系统信息、用户/权限、
CPU/内存、内核调优、磁盘/IO、进程/服务、JVM 排查、网络、SSH、日志、文件、文本处理、Docker、
容器运行时、Kubernetes、Helm、Nginx、MySQL/Redis、性能压测、GPU、安全审计、备份恢复、日志轮转、
定时任务、证书/密钥、软件包）。

- **搜索**：命令、中文说明、分组名一起搜；多个词是**收窄**（`磁盘 排序` 比 `磁盘` 少）
- **点击 = 填入命令行，不执行**。这些都是带参数的真命令（`docker logs -f --tail 200 $(docker ps -lq)`），
  先看一眼再按回车更稳妥；回车键在有搜索词时填入第一条
- **鼠标划过一行**给出完整命令和作用 —— 长命令在行里会被省略号截断，悬停是看全的地方
- 命令里的名字都是**具体例子**（`deploy/app`、`nginx`、`example.com`），照着改比对着 `<占位符>` 填快
- 没有已连接的会话时，点击改为复制到剪贴板，不静默丢弃
- 面板里的「编辑快捷条」还是原来那套：你自己固定几条，常驻终端下方；
  **快捷条上的每个按钮悬停也会显示作用**（命令如果来自本面板，说明直接跟过来）

数据在 `src/renderer/src/commands.ts` 的 `PALETTE`，纯表格，加一条就是加一行；
`npm run test:commands` 单测会检查分组连续、命令不重复、转义没被吃掉。

## 命令补全

输入时弹出候选，**开在输入行下方**，像输入法的候选条：

| 按键 | 作用 |
| --- | --- |
| `↓` | 从顶部进入候选，依次往下选（终端里会实时把命令行换成候选内容） |
| `↑` | 往回退：选中的退回已输入的内容；一条没选时这个键还给 shell 的历史 |
| `Tab` | 补全到命令行，不执行 |
| `Enter` | 直接执行选中的候选 |
| `Esc` | 收起候选 |

候选有两个来源：**本连接的历史**（优先，最近用过的排前面）和一个**内置常用命令词典**（约 205 条），
每条都带一句中文说明，显示在候选行的右侧。

**命令名打完之后，接着补它的后续选项。** 空格一敲出 `systemctl `，候选就换成这个命令自己的动作
（`status` / `restart` / `reload` / `list-units --failed`…），也都带说明；

```
docker p      →  docker ps -a              所有容器
                 docker pull nginx          （历史，排在最前）
git st        →  git status                工作区状态
git stash      →  git stash pop            把暂存的改回来
```

覆盖 32 个最常用的命令（systemctl、journalctl、docker、kubectl、git、apt/yum、tar、find、grep、
sed、awk、ps、ls、df/du、ss、ip、curl、ssh、scp、rsync、dig、lsof、tcpdump、nginx、mysql、
redis-cli、npm、pm2、supervisorctl、firewall-cmd…），一个命令 5–15 条。

两条硬规则：**候选永远是在你已输入的内容上追加**（绝不会拿一个裸命令名把你打好的参数抹掉），
以及**表里不能有工具上不存在的动词** —— 一个看着像的假选项比没有候选更坑。
`src/renderer/src/commands.ts` 纯函数 + 纯表格，`npm run test:commands` 单测兜着。

候选条是**浮层**，不是布局里的一行：它贴在光标所在那一行的下面，像输入法的候选框，
终端本身不被重排——候选时而出现、时而消失时，命令行**不会跳**，远端 pty 的行列数也不会变。
光标已经贴近底部时它翻到上面来，不会伸到面板外面去。点候选行等于按 Tab（填进命令行，不执行）。

`Ctrl+Shift+H` 或工具栏「历史」打开完整列表，可过滤、点击填入、一键清空。

记录是**尽力而为**的：xterm 只把按键原样交给远端 shell，行编辑是 shell 在做，所以这里反向
重建了当前命令行。碰到 Tab 补全、方向键、全屏程序（vim/top）这些会打乱行内容的情况，宁可丢掉
这条记录，也不记下一串控制字符。历史按连接分开存，最多 500 条，开头打空格（shell 惯例）不记。

## 快捷键

`Ctrl+/` 或标题栏的 **⌨** 随时可查。面板分两段：LiteShell 自己的快捷键，和终端里交给远端 shell
处理的那批（`Tab` 补全、`Ctrl+R` 搜历史、`Ctrl+A/E` 跳行首行尾……），后者我们一律不拦。

| 按键 | 作用 |
| --- | --- |
| `Ctrl+T` | 新建连接 |
| `⌘` / `🔑` | 命令面板 / 私钥管理（标题栏按钮） |
| `Ctrl+,` | 设置 |
| `Ctrl+/` | 快捷键一览 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签 |
| `Ctrl+1` … `Ctrl+9` | 跳到第 N 个标签 |
| `Ctrl+Shift+W` | 关闭当前标签 |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | 复制 / 粘贴 |
| `Ctrl+Shift+F` | 终端内查找 |
| `Ctrl+Shift+B` | 文件面板 |
| `Ctrl+Shift+M` | 资源监控 |
| `Ctrl+Shift+H` | 历史命令 |
| `Ctrl+Shift+K` | 清屏 |
| `Ctrl+S` | 编辑器内：存回服务器 |
| `Alt+↑` / `Alt+↓` | 文件面板：上一级 / 进入选中目录 |
| `Esc` | 关闭当前弹窗 / 收起历史候选 |
| 右键 | 会话内为操作菜单；终端内为粘贴 |

快捷键特意避开了 shell 自己的按键（`Ctrl+W`、`Ctrl+R`、`Ctrl+L`、`Ctrl+↑↓`），
所以加 `Shift` 的都是应用功能，不加的留给远端 shell。

连不上先看**标题栏 → 日志**：里面按时间顺序记了连接参数、SSH 握手协商结果、认证方式
和失败原因，可以直接「复制」发出去。

## 主题与密码

- **主题**：标题栏「🎨」→ 7 套内置配色，亮色主题连 Windows 原生标题栏按钮一起换色。
  主题是纯数据表（`src/renderer/src/main.ts` 的 `THEMES`），加一套只要往里加一项。
- **终端背景图片**：设置 →「终端背景图片」→「选择图片…」，png / jpg / webp / gif / bmp，
  最大 12 MB。图片画在终端画布后面，配色里那块背景色变成 72% 不透明的遮罩，
  文字压在图片上仍然读得清。**只存路径不存副本**：图片留在你原来的位置，
  删掉或改名之后背景就没了，不会有一份不知道从哪来的副本躺在应用数据目录里。
  点「清除」回到纯色。
- **密码持久化**：从 FinalShell 导入的连接密码搬不过来，第一次点连接会弹框补录；
  勾选「保存到系统钥匙串」并**连接成功之后**才写入——打错的密码不会被存下来。
  没勾选的会每次都问。

## AI 助手

**设置 → AI 助手**里填接口地址、模型和上下文窗口，工具栏上的「AI」就能用了（入口一直都在，没配也会说明要配什么）。
每个标签页一个对话，它跟这台上面的连接绑在一起——换台机器就是新对话。对话会**存在这台连接名下**：
面板右上角「历史」（或工具栏 AI 按钮右键）里点开一条，「继续这个对话」就接着往下问，
它记得之前跑过什么、查到了什么。

面板里的记录是**一步一折叠**，不是一堆飘着的块：每次工具调用和它自己的输出在同一个块里，标题就是它
真正要跑的那条命令（`ls /`、`exec …`），点标题展开/收起。输出超过 600 字或 8 行的默认折起来，
**失败的不管多长都摊开**——出错那几行正是要看的东西。模型在调用工具之前说的那几句算铺垫，
渲染成暗淡的小字，只有真正的回答保留卡片样式。于是一轮对话读下来就是：你的问题 → 几条命令（各带
自己的输出）→ 一段回答，审计的时候顺着标题扫一眼就够了。存下来的历史走的是同一套渲染，重启之后
打开会话，看到的和当场一样。

- **接口地址**单独一格，模型单独一格。填完地址点**「拉取模型」**，模型名从接口读回来变成下拉候选，
  不用自己背；读不到才手填。地址少了 `/v1` 时它会补上再拉一次，并把补过这件事写在下面。
- **Anthropic** 走官方 SDK（`claude-opus-5` 等），**OpenAI 兼容**覆盖 OpenAI / DeepSeek / 自建网关。
  自建网关的地址填到 `/v1` 为止——填成裸域名它多半会把网站首页当接口回给你，症状就是「发出去没反应」。
- **API Key 可以不填**：本地 ollama、内网网关、自带鉴权的代理都不需要。填了就走和密码同一套加密，
  界面上再也读不回来。只要有模型名，面板就算配好了。
- 发送到第一个字之间面板会显示「正在请求 …」；接口报错、超时（两分钟）、回了空内容，都会写在对话里，
  不会一声不吭。
- 只读的 `ls` / `cat` / `monitor` 直接跑；`exec` 里**只看不改**的那一类也直接跑——
  `tail` / `grep` / `journalctl` / `ps` / `df` / `find` / `systemctl status` / `docker ps` 这种，
  条件是一条命令、不带 `&&` `|` `>` `$()`：**白名单，不是黑名单**，所以没见过的命令一律弹卡片。
  `mkdir`、`mv`、`rm`、`systemctl start` 这些照旧每次都问，卡片按风险标绿 / 黄 / 红。
  命令可以改，改完重新过一遍风险判定——不然这张卡就成了洗白别的东西的通道。
- 输出超过 32 KB 自动落成文件，把头尾和 handle 交给模型，它要中间那段再 `read_output` 读回来。
  落盘在本机 `<用户数据目录>/agent-out/`，每次启动清空。
- **传文件**：`upload` 把本机文件传到服务器（本地路径只能来自你的说明，模型不会自己编），
  `download` 把远端文件或整个目录下到本机「下载/liteshell」。两个方向都**每次弹卡片**——
  上传可能覆盖远端同名文件，下载会写进你自己的磁盘。传完的路径会写在结果里。
- **代你配连接**：`list_connections` 列出已有连接和文件夹（只读，直接跑），`save_folder` /
  `save_connection` 新建或修改本机连接——每条都要你点确认，改的是客户端配置，不碰服务器。
  模型**拿不到也填不了密码**：参数表里根本没有密码字段，存下来是一条待补密码的空壳连接
  （`hasSecret: false`），你连的时候它再问你。
- 你批准的命令**打在左边那个终端里执行**——看得见它下命令、看得见输出、`Ctrl-C` 就能掐。
  代价有三个，都是这一条路换来的：终端里那一行会带上分界用的 `printf`（分界本身不显示，命令还是它自己那条）；
  你正在敲了一半的那一行会被清掉；`vim`、`top` 这类全屏程序占着终端时它会拒绝执行，让你先退出来。
- 命令里**不能有换行**（终端一次读一行），要用多行就 `bash -c '…'` 或者先落成脚本。
- 面板默认 520 px 宽，左边那条边可以拖；标题栏的 **⤢** 一下占满整行，专看命令和长回复。宽度记在设置里。
- 按**停止**不是只停请求：它会往终端里补一个 `Ctrl-C`，不让命令在你眼前继续跑。
- 中途换接口或换模型，那段记录在新接口上是读不懂的，所以下一条消息会**从头开始**，面板里会写一行
  告诉你——而不是让每一条后续消息都失败。
- **压缩上下文**：设置里的「上下文窗口（K）」填模型实际能装多少（默认 128），对话占到 **90%** 时
  自动把早先那段交给同一个模型压成一份交接摘要（要跑的命令、路径、数值、报错、被拒绝的尝试、
  还没解决的问题，命令原文照抄），最近约 20% 原样留着。压缩点会在对话里留一行「早先的对话已压缩成摘要」，
  点开就是模型现在手里那份摘要。摘要失败就只丢早先那段，不打断当前这一轮。
